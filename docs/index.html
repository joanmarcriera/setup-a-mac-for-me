§ 02 · macOS defaults

Four small tweaks that earn their keep.

tap to click
defaults write com.apple.AppleMultitouchTrackpad Clicking -bool true
defaults write com.apple.driver.AppleBluetoothMultitouch.trackpad Clicking -bool true
defaults -currentHost write NSGlobalDomain com.apple.mouse.tapBehavior -int 1
defaults write NSGlobalDomain com.apple.mouse.tapBehavior -int 1
dock autohide
defaults write com.apple.dock autohide-time-modifier -float 0.5
defaults write com.apple.dock autohide-delay -int 0
killall Dock
launchpad 10×8
defaults write com.apple.dock springboard-columns -int 10
defaults write com.apple.dock springboard-rows -int 8
killall Dock
three-finger drag

System Settings → Accessibility → Pointer Control → Trackpad Options → enable "Use trackpad for dragging" → choose "three finger drag".

§ 03 · Restore state

The manual part, the one most likely to be forgotten.

Checklist

Browsers. Sign into Vivaldi and confirm sync brings back workspaces, bookmarks, and extensions. Set DuckDuckGo as default.

Editors. Sign into VS Code and enable Settings Sync. Reconnect Codex, Claude, and Antigravity if they are part of the current workflow.

Automation. Import or sync Keyboard Maestro macros and reconnect the launcher and clipboard shortcuts. Activate Rectangle Pro and restore window shortcuts.

Knowledge. Reconnect Obsidian vaults and plugins. Reconnect Logseq graphs and confirm any git-based backup still points at the right remote.

Mail. Restore MailMate accounts, IMAP settings, and message rules. Sign into Slack, Discord, Teams, Outlook, OneDrive.

Capture. Check Shottr and Kap preferences if output folders or shortcut bindings matter. Restore BetterDisplay presets for external monitors.

§ 04 · Verify

Finish with the generated check script.

Verify workstation 
./scripts/verify-setup.sh workstation
Backup

Default answer

If Time Machine to TrueNAS or NFS already gives a full backup and a restore path you trust, there is no need to add Kopia. Run tmutil latestbackup to confirm the latest snapshot, and tmutil destinationinfo to confirm the destination.

Manual pass

Quick checks

Tap to Click and three-finger drag both work. Vivaldi opens as default with DuckDuckGo. Keyboard Maestro shortcuts fire. VS Code, Codex, Claude, OrbStack, Slack, Teams all launch and sign in.
