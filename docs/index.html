Rebuild a Mac, from erased to working

The steps, commands and settings I use to turn a freshly erased Mac into my daily workstation. Work top to bottom, copy each command, and tick each step off as you go.

Written for macOS 26 Tahoe on Apple silicon. App list last reviewed 4 October 2026.

Mac already set up? Go to keep it updated.

  1. 1

    Back up first

    Skip this on a brand-new Mac. On a Mac you are about to erase, make sure a recent Time Machine backup exists and points where you expect.

    If either command says it is not permitted, give your terminal app Full Disk Access in System Settings > Privacy & Security > Full Disk Access.

    Homebrew cannot recreate these, so check they are in the backup or exported somewhere private:

    • Keyboard Maestro macros and Karabiner-Elements rules
    • Obsidian vaults and Logseq graphs
    • MailMate accounts and rules
    • Dotfiles, SSH keys and repo clones with unpushed work

    Leave out caches, node_modules, build output and anything you can download again. The full erase procedure is on Back up and erase.

  2. 2

    Go through Setup Assistant

    • Choose set up as new for a clean rebuild. Migration Assistant from Time Machine is faster, but it brings the old clutter back with it.
    • Sign in with your Apple Account so iCloud, the App Store and Find My are ready.
    • Turn on FileVault when asked.
    • Apple Intelligence is offered during setup. You can change it later in System Settings > Apple Intelligence & Siri.
    • Before installing anything else, install pending updates from System Settings > General > Software Update and restart. Homebrew then installs against the current system.

    Then clone this repo. Later steps run its scripts from the repo folder.

  4. 4

    Install the apps

    Pick a bundle and run its commands. Workstation is the usual day-one install; Minimal and Full are smaller and larger versions of it. Expect the first run to take a while.

    Workstation bundle: the usual day-one rebuild for daily work. 53 formulae, 48 casks, 3 App Store apps.

    Turn on JavaScript to choose the Minimal or Full bundle here, or use the Homebrew catalogue.

    Casks that install drivers, such as Karabiner-Elements and BlackHole, ask for your password and for approval in System Settings the first time they run. Every group, with its own command and notes, is in the Homebrew catalogue.

  5. 5

    Set up the shell and terminal

    Keep zsh plain and portable. Add these lines to ~/.zshrc. Homebrew's own line lives in ~/.zprofile from step 3, so it loads first.

    • If you use Oh My Zsh, keep the plugin list to plugins=(git).
    • Do not add back autojump, zsh-syntax-highlighting or pnpm.
    • In iTerm2, use a dark profile at about 20% transparency, and set Settings > Profiles > Keys > Key Mappings > Presets to Natural Text Editing so Option-arrow moves by word.
  6. 6

    Apply macOS settings

    Tap to click

    System Settings > Trackpad > Point & Click > Tap to click, or run this and log out and back in:

    Three-finger drag

    System Settings > Accessibility > Pointer Control > Trackpad Options. Turn on Use trackpad for dragging and set Dragging style to Three Finger Drag.

    Dock

    Show the hidden Dock without the delay. From the repo, ./scripts/apply-macos-defaults.sh applies the same settings.

    Leave these off

    • App Exposé: System Settings > Trackpad > More Gestures > App Exposé.
    • The Spotlight shortcut, if Keyboard Maestro needs Command-Space: System Settings > Keyboard > Keyboard Shortcuts > Spotlight.
    • The old Launchpad grid tweak. macOS 26 replaced Launchpad with Apps in Spotlight, so springboard-columns and springboard-rows no longer change anything.
  7. 7

    Set up the browser and coding tools

    Browser

    • Make Vivaldi the default browser in System Settings > Desktop & Dock > Default web browser.
    • In Vivaldi, set DuckDuckGo as the default search engine.
    • Sign in to Vivaldi Sync and check that workspaces, bookmarks and extensions come back.
    • Chrome, Chrome Canary and Edge are for compatibility testing, not daily browsing.

    Coding tools

    • Sign in to VS Code and turn on Settings Sync. The Homebrew cask puts code on your PATH.
    • Sign in to Codex, Claude and Antigravity.
    • Containers run in colima with the plain docker CLI. Docker Desktop and OrbStack are not part of this setup.
  8. 8

    Restore app state and licences

    This is the part most often forgotten. Open the password managers first so every other sign-in is quick.

    • Open the KeePassXC database and sign in to Bitwarden.
    • Keyboard Maestro: enter the licence, then import or sync macros and check the launcher and clipboard shortcuts.
    • Rectangle Pro: enter the licence and restore the window shortcuts.
    • Karabiner-Elements: restore the rules and approve its driver when macOS asks.
    • BetterDisplay: restore presets for external monitors.
    • Obsidian and Logseq: reopen the vaults and graphs.
    • MailMate: restore accounts, IMAP settings and rules.
    • Slack, Discord, Telegram and Teams: sign in.
    • Word, Excel and Windows App: sign in with the Microsoft account.
    • Ollama and LM Studio: download your local models again. They are large, so start early.
    • Shottr: set the output folder and shortcuts.

    Keep licence keys in the password manager and app exports in a private backup, never in this repo.

  9. 9

    Check the machine

    From the repo folder, pass the bundle you installed: minimal, workstation or all. The script lists any missing formula or cask and any Dock setting that does not match.

    Turn Time Machine back on for this Mac in System Settings > General > Time Machine, then check by hand:

    • Tap to click and three-finger drag work.
    • Links open in Vivaldi, and searches go to DuckDuckGo.
    • Keyboard Maestro shortcuts fire.
    • docker run --rm hello-world prints its greeting.
    • The first Time Machine backup has finished.

Already set up? Keep it updated

Three scripts in the repo: one updates everything, one shows what has drifted from the repo, and one checks a bundle is complete.

Update everything

Install the updater once:

Preview first, then run it:

It starts with a summary: macOS version, free disk space, the last Time Machine backup, and an upgrade plan that flags major version jumps, beta and canary channels, pinned formulae and macOS updates that need a restart.

It changes nothing unless Time Machine has a backup from the last 7 days and the destination is reachable. Then it asks once per tool: Yes, No, Skip, All or Quit. It covers Homebrew, npm globals, App Store apps through mas, uv, pipx, Volta, rustup, mise and macOS updates, and prints install instructions for any tool that is missing.

When a macOS update is pending, install it and restart first, then run update-mac again.

  • --dry-run shows what every tool would do and changes nothing. It skips the Time Machine check.
  • --yes runs without prompts. It does not stop for a pending macOS update.
  • --greedy-casks also upgrades casks that update themselves.
  • --skip-macos lists macOS updates but does not install them.
  • --skip-backup-check skips the Time Machine check, for when your terminal lacks Full Disk Access.

See what changed since setup

Compares what is installed (Homebrew formulae, casks and App Store apps) with the repo. It lists what you added by hand, what is missing, and the commands to close each gap. It only reads; it changes nothing.

  • --bundle workstation compares against one bundle instead of every group.
  • --ignore FILE skips tools you keep out of the repo on purpose. It reads ~/.config/mac-drift-ignore by default when that file exists.
  • --json prints one JSON object for scripts. The exit status is 1 when it finds drift, so it works from cron or launchd.

Check a bundle is complete

Run ./scripts/verify-setup.sh workstation from the repo folder, as in step 9.

Decisions and exclusions

Why the list looks the way it does.

  • Keyboard Maestro replaces Alfred, Raycast and separate clipboard managers.
  • colima and the docker CLI replace Docker Desktop and OrbStack: free, scriptable, no licence.
  • Volta manages Node.js and mise handles other runtimes. pnpm stays out.
  • KeePassXC replaced KeeWeb, whose desktop releases stalled.
  • MailMate stays on mailmate@beta because the stable cask needs Rosetta 2.
  • Word, Excel and Windows App come from the App Store. Windows App replaces Microsoft Remote Desktop, whose cask is gone.
  • OpenTofu is used instead of Terraform.
  • App Exposé stays off.

Everything dropped from the rebuild, with the reason, is listed at the end of the Homebrew catalogue.

Commands come from data/install-groups.json, which also generates the Brewfiles.
